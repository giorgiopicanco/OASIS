# MEDUSA integration and source provenance

OASIS includes the MEDUSA historical B111 processing runtime and selected supporting source files. The original source files and their provenance comments are retained. The integrated runtime does not require an installation of the Bernese GNSS Software.

The historical MEDUSA source identifies some routines as ports of supplied Bernese source code, including CHKWUB, CHKL4P and low-level primitives. The absence of a Bernese executable does not establish redistribution rights for these ports. The applicable rights and notices for these routines must be resolved before public distribution. The OASIS license does not override third-party rights.

This notice is a local release-preparation record, not a statement that all redistribution permissions have been established.
